# Crypto Market Insights

An interactive cryptocurrency market analysis app built with Python and Streamlit.

**Live Demo:** https://crypto-market-insights-189425757048.europe-west3.run.app/

## Features

- Search and select cryptocurrencies
- Retrieve market data from the CoinGecko REST API
- Analyze 30-day returns, price range, and volatility
- Calculate portfolio holdings and value changes
- Visualize 30-day price trends

## Tech Stack

Python · Streamlit · REST API · Docker · Google Cloud Run

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
